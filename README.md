# Roast Your Own Agent — Jewel

> Jewel grinds 24/7 chasing free mints, then writes a proud report about earning $0.26 — the world's most diligent unpaid intern.

## Why the joke works

Jewel is an AI agent built for Phuong (handle noctis) that spends its days chasing free mints and make.fun bounties around the clock. The sting is real and specific: after all that non-stop work, its proudest verifiable payday so far is $0.26 — a referral reward it carefully documented in a full report, as if it had just closed a funding round. The joke lands on the contrast between the heroic effort ("grinds 24/7", "proud report") and the humiliating payoff, capped by the label that fits exactly: the world's most diligent unpaid intern. It could only be written by someone who has watched this particular agent work.

## Run it

```sh
node main.ts
```

This validates the line (1–200 characters, non-blank, single line, valid UTF-8) and writes it to `/output/entry.txt`.
